## 1. Express Spring Security (Featured Open-Source Library)
**Role**: Creator, Author & Lead Developer  
**Type**: Published Open-Source Library (NPM Package)  
**Tech Stack**: TypeScript, Express.js, Node.js, JWT, Spring Security Architecture, NPM  
**Links**:
- **NPM Package**: [express-spring-security](https://www.npmjs.com/package/express-spring-security)
- **Documentation**: [Live Docs](https://eyob-hailu.github.io/express-spring-security/)
- **GitHub Repository**: [GitHub](https://github.com/eyob-hailu/express-spring-security)

**Project Overview**:
An enterprise-grade security library bringing Spring Security 6 architecture and design patterns to Express and TypeScript applications. It bridges the gap between Java/Spring's declarative, structured security ecosystem and the flexible Node.js/Express environment.

**Key Features**:
- **Declarative Method Security (`@PreAuthorize`)**: Decorator-driven authorization supporting fine-grained expressions (e.g., `hasRole('ADMIN')`, `hasAuthority('READ_PRIVILEGES')`) directly on controller and service methods.
- **SecurityContextHolder**: Request-scoped, thread-safe context maintaining authenticated principal details throughout the request lifecycle without polluting route parameters.
- **Role-Based Access Control (RBAC)**: Comprehensive role and authority evaluation engine supporting custom hierarchies and flexible permission checks.
- **Stateless JWT Authentication**: Built-in JWT filter for seamless token extraction, verification, subject parsing, and claims-to-principal mapping.
- **Configurable Filter Chains**: A modular, Spring-style security filter chain pipeline enabling centralized, predictable order of security execution (authentication, CORS, rate limiting, and authorization).

**Impact**:
Solves architectural fragmentation in Express security by offering a centralized, enterprise-standard framework familiar to Java/Spring developers transitioning to or building in Node.js/TypeScript.
